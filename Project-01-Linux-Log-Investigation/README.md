# Project 1: Linux Log Investigation

## Overview
A hands-on investigation of Linux login records, user sessions, sudo activity and authentication-related system logs using Kali Linux.

## Objective
To develop practical SOC Analyst skills in Linux log analysis, authentication monitoring and security event investigation.

## Tools
- Kali Linux
- journalctl
- grep
- last
- who
- stat
- file
- strings

## Status
Investigation completed. Documentation and evidence upload in progress.
