# SOC Analyst Portfolio

**Investigating. Learning. Documenting. Improving.**

Welcome to my hands-on cybersecurity portfolio. This repository documents my practical journey toward a **SOC Analyst** role, with a focus on security monitoring, log analysis, threat detection and incident response.

I believe good security work starts with asking the right questions, checking the evidence and documenting findings clearly. That is the approach I bring to every lab.

## What I'm Building

- **Linux security investigations** — reviewing system and authentication logs
- **Network analysis** — understanding traffic, ports, services and suspicious connections
- **SIEM monitoring** — working with Wazuh to review and investigate security alerts
- **Intrusion detection** — exploring Suricata alerts and network events
- **Incident response** — recording evidence, assessing findings and recommending next steps

## How I Approach an Investigation

1. Define the question and scope.
2. Collect relevant logs or network evidence.
3. Use appropriate tools and commands.
4. Check what the evidence supports — and what it does not.
5. Document findings and practical recommendations.

**All activities are performed in my own authorised lab environment.** I distinguish confirmed findings from assumptions and clearly label work that is still in progress.
